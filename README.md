# Distribuicao Binomial

Trabalho de Estatistica: calculadora da formula binomial feita em HTML, CSS e JavaScript.

P(x) = C(n,x) . (p)^x . (q)^(n-x)

Calcula as duas situacoes pedidas:

1. Probabilidade binomial individual: P(X = x)
2. Probabilidade binomial acumulada: P(X <= x)

Alem do resultado, a pagina mostra a resolucao passo a passo, a media, a variancia,
o desvio padrao, um grafico e a tabela da distribuicao.

Pagina online: https://lmagalhaesz.github.io/binomial-web/

## Arquivos

- index.html - estrutura da pagina
- style.css - estilo
- binomial.js - as funcoes de calculo
- app.js - le os dados do formulario e mostra os resultados
